# Objetivo do projeto

> Este documento possui o objetivo do projeto, qual o objetivo final do projeto, qual é a dor que esse projeto resolve.

## Objetivo primário:

Este repositório tem como objetivo realizar o desenvolvimento de uma aplicação de monitoramento proativo multiplataforma de ecommerces, Shopify, VTEX, Wake, Deco, Nuvemshop, Doca e muitas outras plataformas de ecommerce.

- Monitoramento de jornadas dos usuário mapear erros de navegação não encontrados durante o desenvolvimento

- Atuação proativa para criação de tickets em plataformas de tarefas dos times responsáveis pelo projeto.

- Entender jornadas do usuário e enteder melhor como pode melhorar a experiência do usuário com a sugestão de novas correções ou implementações.

### Objetivos importantes:

O objetivo primário e o coração da aplicação mas não é tudo que a aplicação deve representar.

- Aplicação escalável, a aplicação deve possuir uma arquitetura escalável e multi instanciação, como a ideia é monitorar várias lojas, cada uma deve ter suas funcionalidades separadas evitando que uma loja atrapalhe em outra.

- Monitoramento e reaproveitamentos de logs, identificar logs que já estão em execução ou que já foram abertos para cotação, evitando que aconteça um loop de criação de tickets.

- Gravação das sessões dos usuário com o objetivo de melhorar a experiência, coletando e gerando feedback sobre jornadas com carrinho abandonados.

- Notificar/Alertar os desenvolvedores quando erros em runtime acontecem, acelerando a investigação e mitigação.

- Compatibilidade com várias plataformas, oferecer um SDK que seja compatível com browser facilitando a implementação.

- Painel do usuário para os usuários/assinantes do aplicativo poderem fazer login e também realizar o acompanhamento das descobertas, erros encontrados, falhas registradas e quais tickets estão sendo criados.

- Painel administrativo, visão semelhante a do usuário mas tendo em vista que ele pode alterar visão de dashboards, alterar entre os dominios das lojas monitoradas, facilitando a visualização geral.

- Conexão com várias plataformas de gerenciamento de ticket, Jira, Monday, Runrunit, Linear e outras.

- Acesso para usuários da equipe de desenvolvimento.
