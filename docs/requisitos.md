# Requisitos do projeto

> Este documente contém um indice com resumo e link para a documentação completa do requisito

## Monitoramento

- Monitoramento ativo de várias lojas e sites.

- Envio de notificações para os desenvolvedores responsáveis.

- Captura e abertura de ticket com informações do erro

- Registro em banco de dados do erro.

## Plataformas

- Utilizar API de plataformas de controle de tarefas. (Runrunit por enquanto, fase 2° vai tratar de expandir)

- Monitoramento de diversos ecommerce em várias plataformas diferentes, Vtex, Wake, Shopify, Deco e outras.

- Utilização de tags durante o envio para identificar a loja e o cliente.
