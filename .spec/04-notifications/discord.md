# Envio de notificações via Discord
----

Criado em: 28/07/2026
Autor: Netinho

## As notificações

Após uma tarefa ser criada no Runrunit, e o sistema receber de volta a mensagem com status code 200 ou 204 o sistema deve enviar uma notificação no Discord para notificar a equipe que foi encontrado um bug e o ticket para analisar foi criado.

## Futuro da aplicação

A v1 contempla somente o Discord, mas deve ser feito uma arquitetura que seja plausível e fácil de plugar outras plataformas, `Slack`, `WhatsApp`, `Gmail` entre outras.
